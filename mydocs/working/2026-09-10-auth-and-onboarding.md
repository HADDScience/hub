# 2026-09-10 — 허브 온보딩과 인증 진입 흐름

## 허브에서 한 일

- 첫 방문에 HADD Hub의 역할을 소개하는 클릭형 튜토리얼을 추가했다.
- 중앙 문구와 서비스 화면 캡처를 배치하고, 주변 오브젝트는 블러와 느린 부유 애니메이션으로 처리해 중앙에 시선이 모이게 했다.
- 장면은 클릭·터치·Enter/Space로 진행하고, 왼쪽 방향키로 이전 장면으로 돌아간다.
- 허브의 기존 `next` 검증과 SSO 진입 계약은 그대로 유지한다. SSO 또는 `next`가 있는 진입은 튜토리얼을 건너뛴다.
- 로그아웃 때 로컬 토큰을 지우고, 같은 오리진이면 Auth.js 로그아웃을 호출한다. 다른 오리진은 쿠키를 직접 지울 수 없으므로 Omnis 로그아웃 확인 흐름으로 보낸다.

## 인증 화면에서 확인된 문제와 연결

실제 로그인 화면은 Omnis가 소유한다. 허브는 비밀번호 입력을 제공하지 않는다. 따라서 비밀번호 표시, 로그인 화면 높이, 소셜 로그인 오류 처리는 Omnis 저장소에서 수정했다. 허브가 별도 로그인 화면을 만들면 이 저장소의 단일 로그인 계약을 깨뜨린다.

## 검증

서비스 화면 캡처와 튜토리얼은 로컬에서 확인했다. 허브 변경은 PR #1(온보딩)과 PR #2(로그아웃)로 머지되어 다음 `hadd-website` 배포에 포함된다.
