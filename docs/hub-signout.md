# 허브 로그아웃

허브 토큰만 삭제하면 Omnis에 남은 Auth.js 쿠키가 다음 로그인에서 새 SSO 토큰을
바로 발급한다. 로그아웃은 허브 저장 세션 삭제와 HADD 계정 쿠키 종료를 함께 수행한다.

같은 오리진에서는 Omnis의 `/api/auth/csrf` → POST `/api/auth/signout` →
GET `/api/auth/session` 순서로 처리한다. CSRF 값을 검증하고, 쿠키가 실제로 사라진
것까지 확인한 뒤 로그인 화면을 표시한다. HttpOnly 쿠키를 클라이언트에서 직접
덮어쓰지 않는다. Auth.js 기본 로그아웃 프로토콜을 이용한다.

네트워크 오류·불완전한 응답·세션 잔존은 실패 화면으로 보낸다. 재시도할 수 있고,
미완료 상태를 localStorage에 기억하므로 새로고침으로 즉시 재로그인되지 않는다.

개발 서버처럼 발급자와 오리진이 다르면 브라우저가 쿠키 요청을 허용한다고 가정하지
않고, 발급자의 기본 로그아웃 확인 화면으로 이동한다. 그 화면에서 종료한다.
Google·카카오 제공자 자체의 로그인과 다른 기기의 세션을 종료하는 기능은 아니다.
이미 다른 도구에 발급된 앱별 SSO 토큰을 서버에서 일괄 폐기하지도 않는다.

## 검증

```sh
pnpm exec playwright install chromium
pnpm test:auth
pnpm lint --max-warnings 0
pnpm build
```

브라우저 테스트는 별도의 로컬 서버(3011)를 실행하고 인증 API를 목킹한다.
HttpOnly 쿠키 삭제 후 재로그인, 네트워크 실패·새로고침·재시도, 성공 응답에도
쿠키가 남는 경우, CSRF 응답이 잘못된 경우를 검증한다.
